# Docs rules

- One page per benchmark in `doc/<section>/<name>.rst`, listed in its section index.
- Page order: one-paragraph summary → Setup (sketch in `_static/setup/`, generated by
  `_scripts/`; Inputs; Metrics; Run) → Changed parameters (`_generated/.../params.rst`)
  → Results (`plots.rst`, `key_results.rst`, then 3-5 bold-led findings with numbers)
  → Changes since the previous snapshot (`changes.rst`).
- Numbers on a page come from `_generated/` (the committed snapshot), never typed in by
  hand, except the findings, which quote the snapshot.
- State what the results show, not whether they pass; compare with the references.
- `sphinx-build -W` must pass, and the build must leave `doc/_generated` unchanged.
- Refresh the snapshot only from a full run (`pixi run docs` after `pixi run benchmark`),
  in its own commit.
